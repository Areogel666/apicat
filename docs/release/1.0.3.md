# ApiCat 1.0.3 Release Notes

**发布日期**：2026-08-24
**版本类型**：Stable Feature Release

---

## 关于此版本

ApiCat 1.0.3 的核心是 **主题工作室**——在 1.0.2 CSS Token 底座之上，补齐了完整的自定义主题能力：4 套预设一键切换、核心配色自由编辑、密度/字号/圆角三档风格、实时预览与一键回退。

同时，本版本修复了 1.0.2 遗留的一批影响使用的缺陷：Body 多格式互转、URL 参数与 Params 双向同步、Linux 平台兼容、curl 导入、实例 Tab 保存跳转等。

如果你一直想要一个"长在自己的 API 工具"，或者正在被 Body 格式切换、URL 参数同步这些细节折磨——1.0.3 会带来明显的体验提升。

## 重点功能说明

### 🎨 主题工作室

1.0.2 铺好了 CSS Token 底座，1.0.3 把"改主题"做成了完整的工作台：

- **4 套预设主题**：默认 / 深蓝 / 紫苑 / 森林绿，一键切换；预设只定主色，深浅模式独立选择
- **核心 Token 编辑器**：按中性色 / 品牌色 / 语义色 / 形态 4 组折叠面板组织，色板推荐 + 颜色选择器，支持单个 Token 重置 / 全部重置
- **对比度检查**：实时校验自定义色值的前景/背景对比度是否达到可读标准（WCAG AA），低于阈值给出提示
- **主题导入导出**：一键导出 `theme-*.json` 分享给团队，或导入他人主题统一风格

### 📐 风格三档切换

布局密度、圆角、字号三种风格维度，每档切换都即时作用于整个界面：

- **密度**：紧凑 28px / 默认 32px / 宽松 38px 行高
- **圆角**：小 / 中 / 大三档
- **字号**：小 / 中 / 大三档
- 三档通过 `<html data-density>` / `data-font-size>` 驱动 CSS 变量，**每屏可见的骨架组件**（顶栏、侧边栏、主面板、响应区、标签栏）全部接入，预览卡片同步反映

### 🔄 实时生效与回退机制

- 修改配色 / 风格**立即生效**，不再需要点"应用主题"
- 打开工作室时**缓存当前主题快照**；不满意可点「回退主题」，一键恢复到打开前的状态
- **关闭弹窗自动保存**，重启后偏好保留

### ↔ Body 多格式互转

修复了切换 Body 格式时参数丢失/不转换的问题：

- URL Encoded ↔ JSON ↔ Form Data ↔ Text 五种格式完整互转
- 切换后已配置的参数自动转换为目标格式，不再出现"切完是空的"的情况

### 🔍 Ctrl+F 两段式搜索

- 鼠标悬停响应区按 `Ctrl+F` → 全展开 JSON 树所有节点
- 再次按 `Ctrl+F` → 自动切到 raw 模式并由浏览器原生搜索接管
- 处理了手动收起节点后再次搜索的场景（每次都会重新展开）
- Linux 平台：第二次按键主动调 `window.find`，修复搜索失效问题

### ↕️ 三处分栏拖拽

新增通用 `ResizableSplitter` 组件，三处分栏都支持手动拖拽：

- 侧边栏 ↔ 主面板（左右）
- 请求区 ↔ 响应区（上下）
- 用例列表 ↔ 历史详情（左右）
- 拖到边界自动停止，不会让某栏消失

## 重要修复

### 🔧 功能修复

- 修复 Linux 系统点击用例后用例列表与历史记录栏变空白的问题（强制 NDataTable 高度 + 防重复激活）
- 修复修改 URL 参数时 Params 的 KV 文本 / JSON 模式不跟随同步的问题
- 修复 Body 参数在 URL Encoded / JSON / Form Data 间切换不自动转换的问题
- 修复从 curl 导入 POST 请求时 `--data-urlencode` 参数丢失的问题
- 修复切换实例 Tab 后保存接口跳回第一个实例、数据未保存到当前实例的问题
- 修复 Linux 响应面板 Ctrl+F 第二次无法搜索的问题

### 🛡️ 稳定性修复

- 加固 migration SQL 解析器：多行注释过滤，避免注释中分号字面量被误拆导致启动崩溃
- 修复 HtmlPreviewRenderer 在 Dark 模式下 iframe 内主题不跟随的问题

---

## 工程与维护改进

- **CSS 变量全量化收尾**：核心布局骨架全部接入密度/字号/圆角变量，风格预设影响面从"少数几处"扩大到"每屏可见"
- **响应渲染器 token 化**：JSON / Markdown / Code / HTML 四种渲染器替换为 token 配色，主题切换不再出现"骨架跟随、内容不跟随"的不一致
- **主题系统状态机**：新增快照 / 回退 / 关闭自动保存机制，编辑体验从"改完保存"变为"即改即得"
- **通用分栏组件**：`ResizableSplitter` 抽成可复用组件，后续新增分栏可复用
