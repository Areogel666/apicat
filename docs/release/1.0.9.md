# ApiCat 1.0.9 Release Notes

**发布日期**：2026-10-15
**版本类型**：Feature Release — 树折叠持久化 + 统计级联筛选 + 应用问诊技能 + 首启导览 + 玻璃主题

---

## 关于此版本

1.0.8 回答了「新用户怎么上手」，1.0.9 聚焦「日常使用更顺手、界面更有质感」：

- **浏览效率**——三棵侧栏树的折叠状态按项目记忆（重启/切项目不丢），并补上「全部展开 / 全部折叠」批量操作
- **数据洞察**——使用统计支持「项目 → 接口」级联筛选，KPI 与全部分布图跟筛选走
- **AI 生态**——第 5 个内置技能 `apicat-doctor`（应用问诊）：扫描接口库给出规范整理计划，严格只读、只开方不抓药
- **上手体验**——首次启动的聚光灯功能导览（5 步走完四个面板与 ⚙️ 菜单），并清掉与导览重复的零散提示
- **视觉**——圆角预设从此真正作用到全部 NaiveUI 控件；新增「冰晶」玻璃质感预设，模糊强度与表面透明度可自定义

---

## 核心更新

- **侧栏树折叠持久化**：接口树 / 字典树 / 文档树统一为受控展开，状态按「树 × 项目」存 localStorage——切项目各自记忆、重启不丢；字典树不再被数据刷新强制重置为全展开；文档树补「点目录名即折叠」
- **全部展开 / 全部折叠**：三棵树搜索行各加 ⊞ / ⊟ 按钮，批量操作与手动收展共用同一条持久化链路
- **统计级联筛选**：toolbar 加「项目 → 接口」两个联动下拉；请求数 / 成功率 / 趋势 / 状态与方法分布 / 压测次数全部跟筛选走；接口总数项目级 = 该项目存量、接口级 = 1；字典与文档存量跟随项目口径（字典树同口径：项目自有 + 全局共享），接口级筛选时隐藏
- **apicat-doctor 应用问诊技能**：扫描接口 / 用例 / 字典 / 字段绑定 / 环境 / Cookie，输出分级发现清单（🔴 一致性 / 🟡 元数据 / 🟢 锦上添花），问答细化后在对话内交付整理计划（命名统一、冗余合并、缺失补充，逐条标注执行方）；**严格只读**——SKILL 写死仅允许 GET，实施交给 apicat-edit / apicat-test-gen / apicat-doc-gen
- **Bridge 扁平端点**：`GET /list_requests?project_id=N` 返回项目下跨目录全量接口（问诊扫描与统计拉取共用，替代三跳拼接）
- **首启功能导览**：首次启动播种完成后自动开始 5 步聚光灯 tour（接口树 → 字典 → 文档 → 统计 → ⚙️ 菜单）；应用生涯仅一次、不随版本重弹；中断也不吞后续的技能引导与更新检查；⚙️「重看新手引导」可重开
- **引导去重**：移除活动栏字典/统计两个 popover 提示（与 tour 重复），保留 tour 覆盖不到的功能内提示条（GuideBar × 5 + 首个请求文案）
- **圆角预设联动修复**：`naiveOverrides` 补 `borderRadius(Small)`——此前圆角预设（小/中/大）只作用于自定义组件，n-button 等 NaiveUI 控件永远内置 3px 直角
- **冰晶玻璃预设**：第 5 套预设主题——卡片/弹窗半透明 + backdrop blur + 高光边框与浮起投影，深浅主题各一套视觉语言；旧 webkitGTK 不支持 blur 时天然降级为纯半透明
- **玻璃可自定义**：主题工作室加「玻璃质感」开关（任意预设可组合）+ 模糊强度三档（8/14/22px）+ 表面不透明度三档（62%/72%/85%），全部持久化
- **压测修复**：压测 Tab 发起的压测完成后自动弹出报告（此前只停在「✅ 完成」）；压测历史时间显式按 UTC 解析转本地（此前整体偏移时区差）；曲线区高度可拖拽（120–600px，重启保留）、历史区改为内部滚动
- **URL 环境标识直达**：双击 URL 输入框中的 `{{var}}` 占位符直接打开环境管理，就地编辑或切换环境

## 重点功能说明

### 🌲 侧栏树折叠与持久化

- 持久化粒度为 **树 × 项目**（`tree.expanded.{interface|dictionary|docs}:{projectId}`）：接口集合 id 与文档目录本就属于项目，按项目存才符合「记住」的语义
- 严格恢复语义：持久化值即用户上次操作后的展开集合，恢复时过滤已删除节点；新建字典/文件夹默认收起，点开一次即入持久化
- 接口树搜索期间暂停写盘（搜索自动全展开是瞬时状态），清空搜索恢复搜索前快照——搜索态关应用不会丢折叠布局
- 首次默认态维持旧行为：接口树前 3 个集合、字典层全展开、文档树全收起

### 📊 统计级联筛选

- 「全部项目」为默认态，行为与旧版完全一致；筛选后请求类指标在 SQL 层过滤（接口级走 `request_id` 索引直查，项目级经 `api_requests → collections` 两跳）
- 接口级筛选时字典/文档区块隐藏，Rust 侧同步跳过对应查询与磁盘扫描（不做无效功）
- 空结果文案区分：「所选范围内暂无请求数据」vs 全库空态

### 🩺 apicat-doctor 问诊技能

- 流程：问诊意图确认（可附团队规范文档作对照标准，支持文件路径或粘贴）→ `AskUserQuestion` 多选项目 → 只读扫描 → 分级发现清单 → 问答细化 → 对话内交付整理计划
- 判断原则内置防误报：重复接口按 `method + url` 高置信判定；全局字典（`project_id` 为空）跳过「项目内无引用」判定；断言是 JSON 字符串需解析后判断
- 与既有技能的边界写死在 description：加接口/改接口 → apicat-edit，生成用例 → apicat-test-gen，问诊不开方不抓药

### 🧭 首启功能导览

- 触发条件：`guide.tour` 未看过（应用生涯一次性）+ 等待示例播种完成（`sidebarReloadTick` 信号或 800ms 兜底）——保证第一步接口树有内容可看
- 实现为 highlight 单步模式自驱状态机：每步先切面板、等 DOM 就绪再高亮，绕开 driver 同步步进与面板 v-show 异步 patch 的时序坑；X/Esc/遮罩三条关闭路径统一走 `onDestroyStarted` 收尾
- popover 样式走项目 token（随主题联动）；文案集中在 `guideContent.ts` 的 `TOUR_STEPS`

### 🧊 玻璃质感

- 半透明表面色**不放**预设 tokens（customTokens 跨主题持久，深色 rgba 切浅色会不可读），由 themeStore 按「当前深浅模式 + 透明度档位」动态注入——一键切浅色自动换浅色玻璃
- 透明度档位换整串 rgba 而非 CSS Color 4 的 `rgb(/alpha)` 语法——后者旧 WebKit 不支持
- 纯色底上 backdrop blur 模糊不出差别，玻璃观感主要靠高光边框 + 斜向反光渐变 + 浮起投影三件套传达

## 工程与维护改进

- 新增 `useTreeExpanded` composable（三树共用持久化逻辑，含搜索期暂停写盘）
- Bridge `list_requests` 双参化（`collection_id` / `project_id` 二选一，400 文案同步更正为 snake_case）
- 新增 IPC `list_project_requests`（统计拉接口清单一次扁平查询，替代逐目录 N+1）
- `get_usage_stats` 加 `project_id` / `request_id` 可选参数（旧调用兼容），范围筛选逻辑抽 `scope_filter_sql` 并附单测（四种范围组合锁口径）
- 压测报告弹出协调收敛在 MainPanel（只有它区分两个入口，避免报告/结果弹窗叠加）；done 事件先 emit 后落库，前端延迟 300ms 再拉历史
- 历史时间显示统一走 `utcStringToTs` 显式 UTC 解析（WebKit 对无时区标记串按本地时区解读的坑）
- 新依赖仅 `driver.js`（约 6KB，无传递依赖）

## 兼容与升级

- **数据库**：无 schema 变更
- **IPC**：`get_usage_stats` 新增两个可选参数（不传即全量，旧调用兼容）；新增只读 `list_project_requests`
- **Bridge**：`GET /list_requests` 新增可选 `project_id` 参数（原 `collection_id` 用法不变）
- **app-settings.json**：新增 `theme.glass / theme.glassBlur / theme.glassAlpha`、`guide.tour`；`guide.dictionary / guide.stats` 键废弃（残留无害）
- **依赖**：新增 `driver.js`；无其他新依赖
- **技能**：新增 `apicat-doctor`，安装器名单已更新——老用户启动自动补装到各 Agent 的 skills 目录
- **localStorage**：新增 `tree.expanded.*`、`layout.stressChartHeight`
