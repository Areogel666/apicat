# ApiCat 1.0.10 Release Notes

**发布日期**：2026-11-11
**版本类型**：Feature + Stability + Performance Release — 用例工作流重构 + 请求透明化 + Linux 稳定性 + 编辑体验修复

---

## 关于此版本

1.0.10 主要围绕四件事：

- **用例工作流**——管理面板从左右分栏改为单列表，支持隐藏/显示与行内重命名；运行用例联动下方响应区与 History；`unauthorized` 用例自动豁免认证与 Cookie 注入
- **请求透明化**——Headers 页签只读展示真正会发出的请求头与命中的 Cookie；补默认 User-Agent；新增逐算法响应解压开关（默认关）与 URL 域名来源提示
- **编辑体验**——修复用例/回填场景的黄点误报、历史回填丢消息、参数 `type: null` 导致发送失败、URL 预览文案不准等问题；响应 JSON 支持时间戳悬停
- **稳定性与内存**——Linux WebKit GPU 渲染触发整机卡死的止血方案（默认禁用 DMABUF）+ 三档兼容渲染开关；关闭 Tab 时回收响应桶、撤销栈与历史缓存，修复同 id watcher 循环

## 核心更新

- **用例管理面板重构**：去掉左右分栏，改为单列表面板；新增批量隐藏/显示、行内重命名入口
- **用例运行联动响应区**：运行结果写入该用例的响应桶，回写 `response_headers` 并刷新 History；网络失败也能看到错误
- **`unauthorized` 用例豁免认证/Cookie**：用例执行默认继承接口 `auth_type/auth_config` 并注入存储 Cookie；`case_type='unauthorized'` 例外豁免两者，避免 401 断言被自动补上的认证/登录态打挂
- **urlencoded 用例 420 修复**：用例执行把结构化 URL-Encoded body 当 JSON 原文发送导致服务端 420；在发送边界统一做幂等 `k=v` 编码，覆盖 IPC 与 Bridge
- **Headers 只读展示**：展示 User-Agent / Content-Type / Authorization / Accept-Encoding，以及按当前 URL/项目/环境命中的 Cookie；真源仍是 `cookies::collect_cookies_for_url`，只读、不进签名/落库
- **默认 User-Agent**：调试与压测 client 统一 `ApiCat/<版本>`，用户手动 UA 行优先覆盖
- **响应解压开关**：支持 gzip / deflate / brotli / zstd，默认关闭；可按算法勾选，保存后即时重建主 client；压测把本次 `accept_encoding` 写进 `stress_runs.config_json`
- **黄点修复**：切换/退出用例、历史回填后重新判脏；签名改为比较解析后的实际 URL + 归一化参数；修复「改回原值仍亮黄点」「切走落库后黄点残留」
- **历史回填修复**：旧快照缺 `description` 时从当前接口定义补全；回填与接口定义指向同一地址时保留相对路径/模板，避免仅 URL 表示不同而误判为脏；补充 `path_params` 回填
- **参数 null 兼容**：导入/旧数据里的 `"type": null`、`"description": null` 不再让 `send_request` 反序列化失败
- **响应时间戳悬停**：字段名像时间且值为 10 位秒/13 位毫秒时，悬停显示本地时间 + UTC
- **URL 域名来源提示**：URL 自带 `http(s)://` 时环境 Base URL 不参与拼接；URL 栏用徽标提示来源，两边 host 不一致时发送前再提示一次；URL 预览文案改为「请求地址预览（不含 Query 参数）」
- **Linux 兼容渲染**：默认 `shm`（禁用 DMABUF），修复 Intel i915 上 WebKit GPU 渲染触发的整机 GPU HANG；新增「兼容 / GPU 加速 / 软件合成」三档，改动需重启；首屏 JS 从约 2.0MB 降到 1.35MB
- **字典树默认折叠**：无持久化记录的项目启动时不再展开全部字典项；已有项目的展开状态保持不变
- **环境 Tag 双击直达**：除 `{{var}}` 占位符外，URL 栏的绿色环境 Tag 双击也可打开环境管理
- **内存回收**：关闭 Tab 时清理 raw + 全部用例响应桶；历史全量缓存按接口/用例作用域清空并限 20 条；关闭 Tab 释放撤销栈与 Ctrl+S 快照

## 重点功能说明

### 🧪 用例工作流

- 管理面板单列表：用例可见性、重命名、删除集中在一处；下方用例条只显示未隐藏的用例，管理面板始终可见
- 运行结果联动：响应写入当前用例桶，History 自动刷新；网络错误也会落到对应桶，不再「看起来没反应」
- `unauthorized` 用例：保持 headers/params 全量、不要带 `Authorization`/`Cookie` 即可测出 401；其他类型无法靠删 header 绕过注入
- URL-Encoded body 在 Rust 发送边界统一编码，修复用例执行 420；手动发送与 Bridge 走同一份实现

### 🔍 请求透明化

- Headers 页签的只读区展示「发送时自动注入」的头；Cookie 预览按当前项目 + 激活环境实时查询，点击可打开 Cookie 管理
- 默认 UA 可被用户手动 `User-Agent` 行覆盖；手动写 `Accept-Encoding` 但解压关闭时，界面会提示响应可能是压缩二进制
- 响应解压只影响响应体，不压缩请求体；解压后 reqwest 会自动移除 `Content-Encoding` / `Content-Length`
- 压测与调试共用同一份设置；压测报告快照记录本次 `accept_encoding`，保证历史数字可解释

### ✏️ 编辑体验

- 黄点 = 编辑区与接口落库值是否一致：URL 只比较按当前环境/path 参数解析后的实际地址，参数/Headers 固定字段顺序并统一 `null/undefined/""`
- 用例激活/退出、历史回填、撤销/重做/恢复后统一重算黄点；退出用例前重新检查用例参数是否有修改，避免静默丢弃
- 历史回填优先保留接口定义的相对路径/模板形态；只有历史记录确实指向不同 endpoint 时才使用快照 URL
- 时间戳悬停只覆盖 JSON 美化视图，raw/文本/代码视图不处理；裸数组元素没有字段名，不识别

### 🐧 Linux 稳定性

- i915 GPU HANG 属于驱动/内核层问题；应用侧默认 `shm` 模式禁用 DMABUF，绕开触发路径
- 三档渲染模式：`auto`（GPU）/ `shm`（默认，禁 DMABUF）/ `software`（禁用合成）；外部环境变量优先于 UI 设置
- 使用桌面项启动时，务必移除 `env WEBKIT_DISABLE_DMABUF_RENDERER=1`，否则会覆盖 UI 的三档开关
- 统计面板 ECharts、JsonViewer、HistoryTab、driver.js 均改为按需加载，首屏更轻

### 🧠 内存与性能

- 关闭 Tab 会清理该接口的 raw + 用例响应桶，避免用例运行产生的大响应体长期留在内存
- 历史全量记录缓存（含响应体）按作用域清空，同作用域最多保留 20 条
- 撤销栈与 Ctrl+S 快照在关闭 Tab 后释放
- 修复 `persistParams` 替换 store 对象导致的同 id watcher 循环（会反复落库/拉历史并抬高 CPU、内存）
- 字典树无持久化记录时默认折叠，减少启动时的字典项 DOM

## 工程与维护改进

- 新增 IPC `apply_network_settings(enabled, algorithms)`：设置变化时即时重建主 HTTP client，避免 plugin-store 落盘防抖导致读旧文件
- 新增 `src/stores/network.ts`（响应解压设置）与 `src/utils/unixTimestamp.ts`（时间戳识别 + 自检）
- Rust `ParamItem` 增加 `description` 并随发送快照落库；`type` / `description` 支持反序列化 `null`
- reqwest 启用 `gzip` / `deflate` / `brotli` / `zstd` feature；zstd 增加 C 编译依赖，构建时间/体积略有上升
- 用例表新增 `hidden` 列（幂等迁移，四处同步）；Bridge 与技能文档同步更新
- 响应缓存新增 `clearRequest`；`persistParams` 改为原地更新字段，避免触发切接口 watcher
- 新增/更新单测：压缩头顺序、null 元数据反序列化；Rust 库内 65 个测试通过

## 升级注意

- **版本号**：1.0.10（package.json / tauri.conf.json / Cargo.toml / 两个 lock 文件已同步）
- **Linux 桌面项**：如果之前为了止血在 `.desktop` 的 `Exec` 里写过 `env WEBKIT_DISABLE_DMABUF_RENDERER=1`，请移除；新版本默认 `shm`，UI 三档设置才能生效
- **自动更新**：Linux 仅 AppImage 支持应用内自动更新；deb 需要手动安装。更新包必须由 CI 用匹配私钥签名，`latest.json` 必须发布（不能是草稿）
- **已知限制**：`json_table` 请求在发送时会拍平成 `raw_json`，历史快照无法还原为 JSON Table；query/header/form_data/urlencoded 已修复
- **字典树**：默认折叠只影响无持久化记录的项目；已有项目点一次「全部折叠」即可持久化
