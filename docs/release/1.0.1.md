# ApiCat 1.0.1 Release Notes

**发布日期**：2026-04-10  
**版本类型**：Stable Patch Release

---

## 关于此版本

ApiCat 1.0.1 是基于 `v1.0.0` 的一次功能增强 + 稳定性修复版本，重点补齐了多标签页工作流、侧边栏拖拽能力，以及一批会影响日常编辑体验的交互问题。

如果你会同时打开多个接口来回比对、频繁切换项目、整理目录结构，1.0.1 会比 1.0.0 明显更顺手。

---

## 核心更新

| 功能 | 说明 |
|------|------|
| 多标签页 | 支持同时打开多个请求标签页，在标签间切换、关闭、恢复工作上下文 |
| 标签状态持久化 | 应用重启或切换项目后，可恢复已打开标签页和激活状态 |
| 侧边栏拖拽增强 | 支持目录拖拽排序，也支持接口在目录树中的拖拽移动；修复 Windows 拖拽失效问题 |
| 草稿与标题联动 | 点击侧边栏打开标签页，接口重命名后同步更新标签标题 |
| 项目切换稳定性 | 修复切换项目或导入数据后侧边栏可能变空的问题 |

---

## 重点功能说明

### 🗂️ 多标签页工作流

1.0.1 引入了完整的标签页体系：

- 新增 `TabBar`，可并行打开多个接口请求
- 支持打开 / 激活 / 关闭标签页
- 新建接口、删除接口时，标签状态会同步更新
- 标签页状态支持持久化，应用重启后可恢复上次工作现场

这让 ApiCat 从“单请求切换编辑”升级为“多请求并行处理”，更适合接口比对、联调和分步骤调试。

### 🌲 侧边栏交互增强

围绕目录树的操作体验，本版本补了两类高频能力：

- **目录拖拽排序**：可直接调整目录顺序
- **接口拖拽移动**：支持在侧边栏中移动接口位置，整理结构更高效

同时，还优化了右键菜单顺序，让“添加接口到此文件夹”这类更高频操作更靠前。

---

## 重要修复

### 🔧 稳定性修复

- 修复切换项目或导入数据后，侧边栏偶发空白的问题
- 修复删除请求后标签页未及时关闭的问题
- 修复创建请求后未自动进入对应编辑上下文的问题
- 修复导入后界面刷新不完整的问题
- **修复 Windows 上侧边栏拖拽完全失效的问题**（Tauri WebView2 默认拦截 HTML5 drag/drop 事件）
- 修复测试用例激活时 URL 为空导致地址栏被清空的问题
- 修复接口加载后 URL 与 QueryParams 不同步的问题（双向同步）

### 🎨 交互与体验修复

- 修复 macOS 下部分滚动体验问题
- 修复 CSS 作用域带来的局部样式异常
- 为删除操作补充确认弹窗，降低误删风险
- 调整若干编辑细节，减少切换和保存过程中的状态错乱
- 侧边栏新增刷新按钮，支持手动重新加载目录树

---

## 工程与维护改进

- 补充了项目级分层知识文档，方便后续维护和协作
- 清理了部分测试生成辅助文件与构建产物忽略规则
- 重构侧边栏拖拽逻辑（`onDrop` 从 250 行精简为 150 行），提取公共辅助函数消除重复代码

这些改动主要面向项目维护，不直接影响终端使用方式，但有助于后续版本持续迭代。

---

## 升级建议

- 如果你当前停留在 `v1.0.0`，建议升级到 `v1.0.1` 以获得更完整的多标签页体验
- 对于频繁整理目录、切换项目、并行调试多个请求的场景，此版本收益最明显
