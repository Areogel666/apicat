# ApiCat 1.1.1 Release Notes

**发布日期**：2026-11-17
**版本类型**：Bugfix Release —— 修复 1.1.0 的应用内更新失败，新增版本回退

---

## ⚠️ 1.1.0 用户请手动更新

1.1.0 存在更新安装缺陷：点击「立即更新」会报 `TypeError: Cannot read private member from an object whose class did not declare it`。
**应用内更新无法用到这个修复**，请到 Releases 页面手动下载 1.1.1 的安装包覆盖安装。

1.0.10 及更早版本不受影响，可以正常通过应用内更新升级到 1.1.1。

---

## 修复

- **更新安装失败**——更新状态把 `Update` 类实例放进了 Vue 的 `ref`，被代理成 Proxy 后，`downloadAndInstall()` 内部读取 `Resource.rid`（WeakMap 私有字段）失败。改用 `shallowRef` 保留原始实例
- **更新弹窗保留**——1.1.0 引入的 Markdown 更新日志弹窗、启动/手动检查的共用状态保持不变

## 新增

- **版本回退**——⚙️ 菜单 →「⏪ 版本回退...」，列出低于当前版本的历史版本，可直接下载安装并重启。仅接受 `vX.Y.Z` 形式的版本号，安装包沿用原有签名校验
- **回退风险提示**——弹窗内明确提示旧版本可能无法识别新版本数据，建议先导出项目备份
- **已知损坏版本不回退**——回退列表自动排除 v1.1.0（其应用内更新安装损坏，回退过去将无法再应用内更新）

## 升级建议

1.0.10 及更早：直接使用应用内更新。
1.1.0：请手动下载 1.1.1 安装包。
