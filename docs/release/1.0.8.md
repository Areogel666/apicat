# ApiCat 1.0.8 Release Notes

**发布日期**：2026-10-10
**版本类型**：Feature Release — 新手指引 + 使用统计面板

---

## 关于此版本

1.0.7 补齐了 Cookie 与文件上传的功能链路，1.0.8 转向另一类缺口：**新用户怎么快速把工具用起来**。

对从 Postman / Apifox 迁移过来的用户，ApiCat 的界面并不陌生，陌生的只有自己的特色功能。这一版没有做强制的分步教程，而是做了一套轻量的**新手指引系统**：首次进入某个功能区时给一条不打断操作的提示（看完即过，⚙️ 菜单可随时重放），首启自动播种一个带真实示例接口与断言用例的项目——装完打开就能点「发送」。

同版新增**使用统计面板**：把你的调试工作量可视化——请求趋势、成功率、状态码与方法分布、字典与文档建设量，一屏总览。全部数据从本地数据库派生，**纯本地、零上报、零埋点**。

---

## 核心更新

- **新手指引系统**：8 处功能一次性引导——数据字典、压测、Cookie、AI 技能、导入、环境管理、使用统计、首个请求
- **首启示例数据**：无任何项目时自动创建 Default Project 并播种「示例集合」：GET/POST `httpbin.org` 两个可直接发送的接口 + 一条断言返回 200 的示例用例
- **指引重放**：⚙️ 菜单「📖 重看新手引导」一键重置，当前面板立即补弹
- **使用统计面板**：侧栏第 4 个面板，KPI 指标条 + 请求趋势 + 状态码分布 + 方法分布 + 字典/文档建设量
- **四档时间窗**：近 30 天 / 近半年 / 近一年 / 全部；KPI、分布图与压测次数跟随档位，趋势粒度自适应（30 天按日、更久按周）
- **图表说项目的语言**：状态码饼图逐桶用 HTTP 状态语义色、方法分布逐条用方法徽章色、趋势线用主题色——明暗主题与密度/字号档位实时联动
- **纯本地承诺**：统计与指引零网络请求、零埋点，界面注明「数据仅保存在本机」
- **统计面板无侧栏**：切换到统计时左侧栏折叠把手与分割条一并隐藏

## 重点功能说明

### 🧭 新手指引系统

**8 处引导清单**：

| # | 功能 | 触发时机 | 形态 |
|---|---|---|---|
| 1 | 数据字典 | 首次切到字典树 | popover，锚在侧栏 📖 按钮 |
| 2 | 使用统计 | 首次切到 📊 面板 | popover，锚在 📊 按钮 |
| 3 | Cookie 管理 | 首次打开 Cookie 弹窗 | 弹窗顶部提示条 |
| 4 | AI 技能管理 | 首次打开「🤖 AI 技能管理」 | 弹窗顶部提示条（只讲用法，不讲安装） |
| 5 | 导入接口 | 首次打开「📥 导入接口」 | 弹窗顶部提示条（突出 Postman Collection 导入） |
| 6 | 环境管理 | 首次打开「管理环境」 | 弹窗顶部提示条 |
| 7 | 压测 | 首次进入压测 Tab | Tab 顶部提示条 |
| 8 | 首个请求 | 主面板空白页 | 引导文案（提示例接口 + Postman 导入） |

**两种形态、两种语义**（刻意不同）：

- **弹窗内提示条**：**显示即记已读**——每个弹窗只在首次打开时出现一次，之后永不再弹（不点关闭也不会重复打扰）
- **侧栏按钮 popover**：点「知道了」才记已读——锚在面板切换动作上，用户可能切过去又切走没看清，确认后再消失更合理

**状态与重放**：已读标记存 `app-settings.json` 的 `guide.*` 命名空间，键不存在 = 未看过（老用户升级后各引导自然触发一次）；⚙️「📖 重看新手引导」清空全部标记，popover 靠响应式立即补弹，无需重启。

**首启播种规则**：仅走「无任何项目 → 自动创建 Default Project」这一分支（`loadProjects()`），播种在后台执行、失败仅告警不阻塞首启；老用户升级不补种、无欢迎弹窗打扰第一屏。示例数据就是普通数据，可随意改删。

### 📊 使用统计面板

侧栏第 4 个面板「📊 使用统计」，纯本地只读聚合（新 IPC `get_usage_stats`），无 Bridge 端点、无任何上报。

**统计口径**（写死，有单测锁住）：

| 指标 | 口径 |
|---|---|
| 请求类（请求数/成功率/趋势/分布） | **只算调试发送**（`test_case_id IS NULL`）——用例执行混入会因「每用例仅保留 10 条历史」的触发器裁剪而失真 |
| 成功率 | `2xx/3xx` 为成功；**无状态码（网络层失败）或 ≥400 为失败** |
| 状态码分布 | 四桶：`2xx/3xx`、`4xx`、`5xx`、`网络失败`（status_code 为 NULL 单列，不被静默丢弃） |
| 方法分布 | 从请求快照 `json_extract('$.method')` 取实际发送方法，取不到归「未知」 |
| 压测次数 | `stress_runs` 按档位窗口 COUNT |
| 接口总数 / 字典 / 文档 | 存量全量（无窗口语义） |

**四档时间窗与粒度自适应**：近 30 天 / 近半年 / 近一年 / 全部。趋势粒度自动切换——窗口 ≤90 天按**日**、更久按**周**（每条记录归到所属周一，规避周编号跨年对齐问题）；固定窗口的空档由前端补零，「全部」档不补零由坐标轴抽稀。

**文档区块口径**：仅统计已在「项目设置」配置文档输出目录的项目（扫描目录下 .md 文件数 / 总体量 / 最近更新时间）；「已写文档的接口数」因文档文件与接口无结构化关联而**不做**（模糊匹配不准），界面有说明文案。

**图表主题联动**：canvas 读不到 CSS 变量，图表色在渲染时从主题 token 取计算值，并通过监听 `<html>` 的 `data-theme / data-density / data-font-size` 变化即时重算——切主题、调密度，图表跟着变。

**已知边界**：趋势基于本地请求历史，「⚙️ 清理历史记录」会挖掉统计底料且不可恢复（界面已注明）——这是本地工具的天然边界，不做备份补偿。

## 工程与维护改进

- `get_usage_stats` 附 6 个单测：内存库跑**真实迁移** + 真实 SQL，锁死口径（用例行排除、NULL 状态桶、空库哨兵、目录缺失容错、周桶必为周一、宽窗口计数）
- `db::run_migrations` / `docs::scan_md_files` 提权 `pub(crate)` 供统计复用（签名不变）
- echarts 为唯一新依赖，按需引入（`echarts/core` + 用到的图表/组件注册），不整包 import
- 播种完成后复用 `sidebarReloadTick` 强刷接口树（与导入接口同一模式）
- 指引状态读写收敛到 guide store 一处，文案集中 `src/config/guideContent.ts`

## 兼容与升级

- **数据库**：无 schema 变更，全部指标从现有表派生，首次启动自动迁移逻辑无感
- **IPC**：新增只读 `get_usage_stats(range)`，无破坏性变更
- **app-settings.json**：新增 `guide.*` 键（缺失 = 未看过），旧配置文件无需任何处理
- **依赖**：新增 `echarts`（按需引入）；无其他新依赖
- **技能/Bridge 契约**：无变化（统计为 UI-only）
