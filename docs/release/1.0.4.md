# ApiCat 1.0.4 Release Notes

**发布日期**：2026-09-16
**版本类型**：Stable Feature Release

---

## 关于此版本

ApiCat 1.0.4 的核心是 **数据字典「字段名绑定」** 与 **参数元数据（类型/描述）的持久化与隔离**。

字典不再是"给某个值打个标签"，而是真正按业务定义的用法：**某个字段名绑定一个字典后，整个项目里所有同名字段自动根据当前取值命中展示含义**，悬停可查看全部枚举；手写描述仍可附加在尾部并随时编辑。字段类型/描述此前在切换接口、切换用例、切换 KV/JSON/Text 模式时会丢失或串扰，本版从数据模型与草稿机制两层做了根治：元数据随接口独立持久化、接口间彻底隔离。

配套补齐了**压测历史常驻 Tab**（结果回看、报告下载、双条对比），以及导出一并携带用例、字典、字段绑定规则。

## 重点功能说明

### 📔 数据字典「字段名绑定」

字典绑定的粒度从此前的"参数行 ⇄ 字典项"改为「**字段名 ⇄ 字典**」：

- 给某个字段（如 `status`）绑定字典后，**同项目所有接口里叫 `status` 的参数自动命中**显示含义；
- 字段当前 `value` 命中字典项 → 描述列绿色标签显示「0 = 成功」；未命中 → 灰字「未匹配」；
- 悬停字典编码 → Tooltip 列出全部枚举，命中项高亮；
- 允许「仅当前接口」例外：对某个接口单独换绑/解绑（带 ⓘ 角标），不影响其它接口；
- 字典管理页可整体把字典（含字典项与字段规则）复制到其它项目。

### ✏️ 参数元数据：类型 / 描述

- 表格里的「类型」与「描述」随接口 `params` 独立持久化，重启、切接口、切用例、切 KV/JSON/Text 都不再丢；
- 描述列在「未绑定字典」时是直接输入框，绑定字典后展示命中信息 + ✎ 可编辑手写描述；
- URL-Encoded 的 body 存储从 `k=v` 文本升级为结构化 JSON 数组（含启用标记、类型、描述），发送时才编码为 `k=v`——老数据加载自动兼容。

### ⚡ 压测历史常驻 Tab

- 编辑区「用例」旁新增「压测」Tab：并发/模式配置即点即用，实时统计与折线图；
- 下方列出本接口全部压测历史（TPS / 成功率 / P95 摘要），可下载 Markdown 报告、双条历史对比、删除；
- 不必先跑一次压测才能看到历史上次结果。

## 重要修复

### 🔧 功能性修复

- 发送请求后切换接口再切回，响应不再消失（响应桶与激活用例同步）
- 切换接口时类型/描述不再串扰到其它接口同位置参数
- 保存后切换用例，类型/描述不再丢失（用例继承接口定义）
- URL 路径中带数字的段（如 `/intl/search1`）不再误判为 Path Param
- Params/Body 表格中「值」移到字段名之后（原排在最后）进行调整
- 新建同名接口（含 curl 导入）不再拦截，改为在已有接口下新增实例并提示
- 右侧上下分栏拖动方向修正（上拖即分界线上移）
- 数据字典图标点击无响应（漏注册 NaiveUI 组件）

## 工程与维护改进

- **字典语义升级**：`field_dictionary_rules`（项目级字段名↔字典）、`field_dictionary_overrides`（接口×字段名例外）两张新表（幂等 migration 0003）；删除废弃的字段行级 `descriptionDictRef` 引用逻辑
- **导出升级 v1.1**：`project.field_rules / field_overrides`；字典按 code 关联，导入对同字段规则去重
- **草稿机制加固**：接口切换时参数数组深拷贝隔离 + 切走时短事务落库并锁定离开接口，消除内存共享与写库竞态
- **布局常驻**：接口树/字典树侧栏与主面板 `v-show` 常驻，而不是卸载重挂，切换不丢浏览状态
- **搜索体验**：绑定弹窗字典列表、字典管理页字典树与字段绑定列表均支持搜索

---

## 兼容与升级

- 新增表均为幂等 `CREATE TABLE IF NOT EXISTS`（migration 0003），老库自动建表；
- 旧参数数据（KV/文本存储）加载自动兼容，无需清库；
- 建议升级：需要字典按字段名统一管理含义、或常被"类型/描述丢失/串扰"困扰的场景收益最直接。
