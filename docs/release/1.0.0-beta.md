# ApiCat 1.0.0-beta Release Notes

**发布日期**：2026-03-31  
**版本类型**：Public Beta  
**构建验证**：`vue-tsc --noEmit` → 0 errors ✅ | `cargo build` → Finished ✅

## 关于此版本

ApiCat 1.0.0-beta 是首个面向公开测试的版本。基于 Tauri 2.0 + Rust + Vue 3 构建，提供无跨域限制的桌面 API 调试体验。本轮 Beta 经历了 12 轮累计修复，涵盖从底层 IPC 协议修复到前端交互重构的全方位打磨。

---

## 核心功能

| 功能 | 说明 |
|------|------|
| 无跨域限制 | 所有 HTTP 请求经由 Rust `reqwest` 原生发送，彻底绕过浏览器 CORS |
| 多认证方式 | Bearer Token / Basic Auth / API Key 一键配置 |
| 环境与变量 | 多环境管理，支持 `{{variable}}` 语法注入 URL、Headers、Body |
| 原生压测引擎 | 基于 `tokio` 异步运行时的并发压测，防 OOM，支持测试用例参数化 |
| 数据迁移 | 导入/导出 Postman Collection v2.1、导入 OpenAPI (Swagger) 规范 |
| 请求历史 | 自动记录请求历史，支持 Diff 对比两次响应差异 |
| 测试用例 | 保存、管理、参数化请求用例，支持压测复用 |
| 公共 Headers 模板 | 复用认证 Token 等公共 Header，一键应用到任意请求 |

## 重要修复（Beta 阶段）

### 🔧 底层 / 架构修复

#### Tauri IPC 参数名修复（Round 1）
- **问题**：Tauri 2.x `#[tauri::command]` 宏将 Rust 参数名自动转为 camelCase，而前端所有 `invoke()` 调用传的是 snake_case，导致大量功能静默失败（环境管理、文件夹创建等）。
- **修复**：全量修正 stores 和组件中 `invoke()` 的参数名为 camelCase。影响 8 个文件。

#### 导入事务嵌套崩溃（Round 5）
- **问题**：Postman / OpenAPI 导入时，直接执行 `BEGIN` SQL 触发"cannot start a transaction within a transaction"错误。
- **修复**：改用 SQLx 标准 `transaction API`，与其他命令保持一致。

---

### 🎨 侧边栏交互重构

#### 接口/文件夹操作按钮（Round 3 → Round 12）
经过多轮迭代，最终方案：
- **行尾操作按钮（`+` / `•••`）**：默认 `opacity: 0` 隐藏，鼠标悬停节点行后显示，通过 `onMounted` 延迟 300ms 激活，防止 Tauri WebView 初始化期间误触发
- 按钮图标从 `⋯` 升级为 `•••`（三点，视觉更紧凑），`+` 按钮专属绿色 hover 效果
- CSS 使用非 scoped `<style>` 块，解决 Naive UI 内部渲染的 DOM 不携带 Sidebar scope 哈希的问题
- `all: unset` 完全重置浏览器默认样式，消除 Tauri WebView 的 `:focus-visible` 边框问题

#### 文件夹 `+` 按钮功能
- 「添加子文件夹」、「添加接口到此文件夹」、「从 cURL 导入」三合一下拉菜单

#### 接口拖拽排序
- 支持同文件夹内接口拖拽排序，持久化到数据库

#### 搜索功能
- 内联过滤（在 `treeData computed` 中过滤），支持不区分大小写的包含匹配，自动展开包含匹配接口的文件夹

---

### 🟡 暂存状态圆点（Round 4 → Round 12）

经过多轮响应式机制探索，最终方案：

- **架构**：用 `defineComponent({ setup() { computed(...) } })` 创建独立 `NodeStatusDot` 组件。核心原因：`renderSuffix` / `renderLabel` 是普通函数，Naive UI 在 `TreeNodeContent.render()` 里调用时不在 Vue 响应式 Effect 里，无法追踪 Pinia store 变化；只有独立组件的 `setup computed` 才有自己的 effect scope。
- **位置**：圆点显示在接口节点的 `•••` 按钮左侧（suffix 区域），始终可见，不受按钮 opacity 影响
- **语义**：橙色圆点（`#f0a020`）= 有未保存的修改；绿色圆点（`#18a058`）= 刚保存成功（1.5s 后消失）
- **响应式保证**：`dirtyRequestIds` / `savedRequestIds` 所有修改均通过**替换整个 Set** 触发 Vue 3 响应式更新（原地 `add`/`delete` 不触发）

---

### ✏️ URL 栏 & 参数面板重构（Round 2 → Round 5）

- **Method 选择器内联**：下拉选择器内嵌 URL 框左侧，不同 HTTP 方法显示不同颜色（GET 绿/POST 蓝/DELETE 红等）
- **URL ↔ QueryParams 双向绑定**：URL 输入 `?key=value` 自动填充 Params 表格；Params 修改自动更新 URL
- **URL 右移重影修复**：高亮覆盖层（用于 `{{variable}}` 变量高亮）仅在 URL 含变量时渲染，修复无变量时的文字重影
- **相对路径自动拼接**：发送时自动检测并拼接激活环境的 `base_url`
- **环境标签**：URL 框旁显示当前激活环境名称标签

---

### 💾 草稿缓存 & 暂存保存（Round 4 → Round 6）

- **草稿缓存**（`draftCache: Map<id, draft>`）：切换接口时自动缓存未保存编辑，切回时恢复，不丢失修改
- **暂存保存按钮**：有未保存修改时显示橙色「💾 保存」按钮，`Ctrl+S` / `Cmd+S` 快捷键触发保存
- **项目管理**：TopBar 下拉支持重命名/删除项目，改用 Naive UI Modal/Dialog 替换 `window.prompt/confirm`

---

### 📊 响应面板改进（Round 7 → Round 9）

- **请求失败提示**：HTTP 4xx/5xx 时额外显示 `❌ 请求失败` 标签
- **自动注入 Headers 提示**：Headers 面板顶部显示发送时自动追加的 Content-Type / Authorization 信息
- **History 面板**：修复 Diff 按钮被遮挡问题（`flex-shrink: 0`），修复历史时间显示时区偏差
- **Body 编辑**：URL Encoded body 支持键值对表格 + KV 文本双模式编辑

---

### 🗜️ 压测引擎增强（Round 8）

- **用例参数化**：压测配置弹窗支持选择已保存的测试用例，用例的 URL / Headers / Body 覆盖当前请求参数后执行压测

---

### 🎨 视觉 & 体验

- **应用图标**：全新小猫风格图标（橙色渐变背景 + 白色猫脸，多尺寸）
- **cURL 导入**：侧边栏 `+` 下拉支持从 cURL 命令导入接口（解析 method / headers / body）
- **测试用例双击重命名**：用例 tab 双击即可内联编辑名称，移除 `window.prompt`

## 已知限制

- 暂不支持跨文件夹拖拽接口
- WebSocket / SSE / GraphQL 不在本版本支持范围内
- 压测结果不持久化，关闭弹窗后丢失
